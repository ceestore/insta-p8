# contas/

Uma pasta por conta do Instagram. O código do sistema (`app/`, `lib/`) é um só; aqui ficam as instruções, a marca, a estratégia e as
ferramentas de cada conta, para não misturar.

- `cee_webstore/`: loja de produtos (CEE Store).
- `cloviseduardo/`: serviço de tráfego pago do Clóvis Eduardo (funil do Raio-X).

Cada pasta tem um `CLAUDE.md` com as regras da conta. Abra uma conversa por conta e comece por ele.
Todo script exige `--conta @nome` (ou `AGENT_ACCOUNT`).
